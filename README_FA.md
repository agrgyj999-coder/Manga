# MangaTranslate — نسخه رایگان آزمایشی

## قابلیت‌ها
- انتخاب یک تصویر مانگا از گالری اندروید.
- OCR روی دستگاه با Google ML Kit و مختصات بلوک‌های متن.
- زبان‌های ژاپنی، انگلیسی/لاتین، کره‌ای و چینی ساده‌شده.
- ترجمه متن هر بلوک به فارسی با endpoint عمومی MyMemory بدون API key.
- نمایش ترجمه روی همان تصویر، ویرایش با لمس متن و اشتراک‌گذاری/خروجی PNG.

## ساخت APK با گوشی و GitHub
1. این ZIP را استخراج کن.
2. در GitHub یک Repository جدید بساز.
3. تمام محتویات این پوشه را در ریشه مخزن آپلود کن؛ `.github/workflows/android-apk.yml` هم باید آپلود شود.
4. شاخه اصلی باید `main` باشد.
5. در GitHub وارد Actions شو و `Build MangaTranslate APK` را اجرا کن.
6. پس از موفقیت، اجرای workflow را باز کن و از بخش Artifacts فایل `MangaTranslate-APK` را دانلود کن.
7. ZIP آرتیفکت را استخراج کن و `app-release.apk` را نصب کن.

Workflow خودش فایل‌های پلتفرم Android را می‌سازد؛ پوشه android لازم نیست داخل ZIP باشد.

## رایگان بودن و محدودیت‌ها
MyMemory یک سرویس عمومی با سهمیه و محدودیت است؛ رایگان و نامحدود یا تضمین‌شده نیست. برای ترجمه اینترنت لازم است و متن OCR به سرویس بیرونی فرستاده می‌شود. اطلاعات خصوصی را وارد نکن.

## محدودیت خروجی تصویر
نسخه فعلی باکس متن OCR را با یک وصله سفید می‌پوشاند و متن فارسی را روی آن رسم می‌کند. روی حباب‌های سفید بهتر جواب می‌دهد، اما بازسازی پس‌زمینه طرح‌دار، پاک‌سازی هنری و جایگذاری دقیق مثل Google Lens نیست. برای آن باید inpainting و تشخیص حباب حرفه‌ای اضافه شود. PDF و ZIP/CBZ هنوز در این نسخه پشتیبانی نمی‌شوند؛ ورودی فعلی عکس است.

این نسخه نمونه اولیه است و قبل از انتشار باید روی دستگاه واقعی تست شود. از محتوای مانگا با رعایت حقوق صاحب اثر استفاده کن.
